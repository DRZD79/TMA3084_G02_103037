# TMA3084 SELab - Lab 1: Pizza Order Calculator

This repository contains Dart programs for calculating pizza order totals based on size and quantity.

## Files
- `switchcase.dart`: Calculates pizza total payment using a `switch` statement.
- `whileloop.dart`: Uses a `while` loop to allow continuous pizza ordering until the user quits.

## Price
- Small (S): $5 USD
- Medium (M): $7 USD
- Large (L): $10 USD

## How to Run
Run the switch case program:
dart run switchcase.dart

Run the while loop program:
dart run whileloop.dart
